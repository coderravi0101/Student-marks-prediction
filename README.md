# Logistic Regression Prediction App

A simple Machine Learning web application built with Streamlit and Scikit-learn.

## Project Structure

```
project/
│── app.py
│── requirements.txt
│── logistic_regression_model.pkl
│── README.md
```

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Features

- Logistic Regression prediction
- Interactive Streamlit interface
- Probability output (if supported by the model)

## Requirements

- Python 3.10+
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib
